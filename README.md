经典打砖块游戏，使用 C++ 开发，包含完整游戏逻辑、关卡系统、分数统计、存档 / 读档功能。

项目特点
经典 Breakout 玩法：挡板、小球、彩色砖块
多关卡系统，难度逐步提升
分数、生命值、关卡显示
存档 & 读档功能
简洁代码结构，适合学习游戏开发基础

游戏规则
左右移动挡板，反弹小球
击碎所有砖块即可通关
小球掉到底部扣除生命值
生命值归零 → 游戏结束
支持中途存档，下次继续游戏

操作说明
← → 方向键：移动挡板
空格键：发射小球
S 键：保存游戏进度（存档）
L 键：读取游戏进度（读档）
ESC：退出游戏
